Catch

  • species_itis : String
    ITIS code of the fish caught
  • disposition : String
    The final disposition or fate of the catch.
  • unit_of_measure : String
    Code for unit of measure used to reference the reported_quantity field
  • market_code : String
    Factors affecting market price (such as size).
  • grade_code : String
    Grade, or how catch was processed.
  • reported_quantity : String
    Numeric quantity of fish caught. Always used in conjunction with unit_of_measure field.
  • nbr_of_fish : String
    Count of fish caught
  • supplier_catch_id : String
    Unique catch id given by the caller. Only used to communicate errors and for updates.
  • catch_source : String
    Source of a fisher’s catch (S = Standard wild-caught; A = Aquaculture; R = Research Set Aside; C = Carred).
    Enum:
    S
    A
    R
    C
  • sale_disposition_flag : String
    Code indicating whether catch was sold, kept, or discarded.
  • catch_additional_attributes : List
    Collection of supplemental attributes defining the catch.
  • sale_disposition_attributes : List
    Collection of supplemental attributes defining the sale.
  • species_attributes : List
    Collection of species-specific supplemental attributes defining the catch.

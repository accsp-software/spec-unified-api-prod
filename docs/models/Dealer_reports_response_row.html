Dealer_reports_response_row

  • event_id : String
    the unique job-id/event_id for this upload assigned by the system
  • upload_date : Date
    when the upload was received
  • process_date : String
    When the upload was processed.
  • total_report_count : String
    total count of dealer reports records received.
  • total_landing_count : String
    total count of landings records received.
  • errored_report_count : String
    total count of dealer reports that were not processed due to one or more errors.
  • errored_landing_count :
    total count of landings that were not processed due to one or more errors.
  • errored_report_Attr_count :
    total count of reports attributes that were not processed due to one or more errors.
  • errored_landing_Attr_count : String
    total count of landings attributes that were not processed due to one or more errors.
  • reports_accepted : List
    details for accepted dealer reports
  • errors : List
    errors messages

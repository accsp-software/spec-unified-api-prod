Permit_compliance_response_row

  • compliant : String
    a flag (Y or N) to identify whether a given permit is compliant
    Enum:
    Y
    N
  • last_record_type : String
    the type of record last entered (P/N) for positive or negative report
    Enum:
    P
    N
  • last_record_date : date
    the date of the last report entered into the system. Format MM/DD/YYYY
  • non_compliance_dates : String
    A list of dates that the dealer is not compliant in the format MM/DD/YYYY that are delimited by a semi-colon.

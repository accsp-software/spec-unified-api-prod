Notification_upload_request

  • p_license_nbr : String
    alphanumeric value representing a user's license number.
  • p_partner : String
    Partner or issuing agency code.
  • p_participant_id : String
    Participant id of a participant associated with p_license_nbr
  • p_vessel_cgn : String
    vessel coast guard number. a vessel coast guard or state registration number is required.
  • p_vessel_srn : String
    vessel state registration number. a vessel coast guard or state registration number is required.
  • p_trip_type : String
    code to define the type of trip. allowed values are C = Commercial, R = Recreational, H = For Hire-Headboat, A = For Hire-Charter.
  • p_device_id : String
    unique identification of a device.
  • p_start_date : date
    trip start date in format MM/DD/YYYY.
  • p_start_time : String
    trip start time in format HHMM.
  • p_arrival_port : String
    port code for the arrival (ending) port.
  • p_notif_type : String
    trip notification type being submitted. Allowed values are 1 = Pre Trip, 2 = Fishing, 3 = Landing, 4 = Post-Trip, 5 = Cancellation, 6 = Hail Out, and 7 = Closed. If no value is provided, Hail Out (Type = 6) is used as the default.
  • partner_attributes : List
    list of optional partner-managed notification attributes submitted as a JSON array.

Neg_trip

  • supplier_row_id : String
    unique identifier given by sender. Useful for updating information and retrieving errors.
  • iss_agency : String
    4 digit identification of the issuing agency of permit
  • start_date : date
    start date of the negative/no fishing report
  • end_date : date
    last date of negative report if a range is being given
  • cf_license_nbr : String
    license number given by issuing agency
  • state_reg_nbr : String
    State Registration number of vessel. If no vessel used, provide 'FROM_SHORE'.
  • coast_guard_nbr : String
    Coast Guard Number/Hull Number of vessel.
  • sector : String
    sector is a trip type value for DNF reports. for COMM_FLAG use sector = 'C' and for FH_FLAG would include (\"Charter\" and \"Headboat\") use sector = 'F'. The sector is a required value for SERO.

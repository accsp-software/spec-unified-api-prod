Trip_upload_error

  • ERR_DESC : String
    Human readable description of error.
  • SUPPLIER_TRIP_ID : String
    supplier_trip_id of record with error. Only shown when error is at trip level.
  • SUPPLIER_EFFORT_ID : String
    supplier_effort_id of record with error. Only shown when error is at effort level.
  • SUPPLIER_CATCH_ID : String
    supplier_catch_id of record with error. Only shown when error is at catch level.
  • EVENT_ID : String
    the event id of error returned.

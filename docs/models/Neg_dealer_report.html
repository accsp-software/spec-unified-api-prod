Neg_dealer_report

  • supplier_row_id : String
    unique id of the report. Used to return errors and for updates
  • iss_agency : String
    4 character identifier of issuing agency of dealer permit in use
  • start_date : date
    first date of reporting range. Format MM/DD/YYYY
  • end_date : date
    last date of reporting range. Format MM/DD/YYYY
  • dea_license_nbr : String
    Permit/License Number of Dealer in use

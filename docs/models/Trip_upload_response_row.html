Trip_upload_response_row

  • event_id : String
    unique ID of this upload process
  • upload_date : String
    date the upload was received by server. Format MM/DD/YYYY hh24:mi
  • process_date : String
    date the server completed processing upload request. Format MM/DD/YYYY hh24:mi
  • total_count : String
    Number of trips found in the upload
  • errored_count : String
    Number of trips NOT processed due to one or more errors
  • trips_accepted : List
    details for accepted trips
  • errors : List
    errors messages

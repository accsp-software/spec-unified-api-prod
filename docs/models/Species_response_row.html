Species_response_row

  • species_qc_id : Integer
    unique row id used to detect changes to current records.
  • species_itis : String
    ITIS code of species
  • species_name : String
    common name of species
  • scientific_name : String
    scientific name of the species
  • uom : String
    unit of measure
  • grade : String
    grade code
  • grade_description : String
    description of grade code
  • market : String
    market code
  • market_description : String
    description of market code
  • min_price : Double
    expected minimum price in US dollars.
  • max_price : Double
    expected maximum price in US dollars.
  • in_use : String
    indicator for whether record is in-use currently
    Enum:
    Y
    N
  • hms : String
    HMS Flag indicator
    Enum:
    Y
    N
  • shark : String
    Shark Flag indicator
    Enum:
    Y
    N
  • area : String
    Flag on whether to collect Area Fished for this species.
    Enum:
    Y
    N

Trip

  • accsp_trip_id : String
    uniquie character number of trip
  • trip_start_date : date
    Calendar date of beginning of fishing trip. Format MM/DD/YYYY
  • trip_end_date : date
    Calendar date of end of fishing trip. Format MM/DD/YYYY
  • trip_type : String
    Trip Type undertaken. Commercial (C), Recreational (R), For Hire-Charter(A), For Hire-Headboat (H)
    Enum:
    C
    R
    A
    H
  • trip_start_time : String
    Calendar time of start of fishing trip. Format hh24:mi
  • trip_end_time : String
    Calendar time of end of fishing trip. Format hh24:mi
  • vessel_permit : String
    Vessel Permit number of vessel in use.
  • trip_activity : String
    Indicator for intended/final outcome of fishing trip.
  • state_reg_nbr : String
    State Registration number of vessel. If no vessel used, provide 'FROM_SHORE'. Required to provide either coast_guard_nbr or state_reg_nbr.
  • coast_guard_nbr : String
    Coast Guard Number/Hull Number of vessel. Required to provide either coast_guard_nbr or state_reg_nbr.
  • port : String
    End Port of vessel.
  • device_id : String
    id number of the device.
  • supplier_trip_id : String
    Unique trip id given by the caller. Only used to communicate errors and updates.
  • participant_id : String
    ACCSP Participant idenitifier of captain reporting.
  • iss_agency : String
    4 character identifier of issuing agency of permit in use
  • cf_license_nbr : String
    Permit/License Number of Permit in use.
  • garfo_vendor_id : String
    GARFO vendor ID
  • garfo_client_id : String
    GARFO client ID
  • garfo_token : String
    GARFO Open ID token
  • vtr_number : String
    Vessel Trip Report number. Auto-generated by the application.
  • efforts : List
    Collection of efforts made with this trip.
  • trip_additional_attributes : List
    Collection of supplemental attributes collected at the trip-header level.
  • trip_update : String
    whether a trip is resubmitted or not
    Enum:
    Y
    N

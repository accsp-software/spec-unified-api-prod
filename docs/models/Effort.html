Effort

  • distance : String
    Distance from shore of fishing location.
  • in_state : String
    State postal if fishing in state waters. 'US' if fishing in federal waters.
  • area_code : String
    3 character area-code of fishing location.
  • sub_area_code : String
    4 character sub-area code of fishing location.
  • local_area_code : String
    Local-area code of fishing location.
  • latitude : String
    Latitude of effort in decimal degrees.
  • longitude : String
    Longitude of effort in decimal degrees.
  • gear : String
    Gear code used in this effort.
  • gear_quantity : String
    Quantity of gear used.
  • fishing_hours : String
    Total amount of active fishing time in this effort.
  • hours_days : String
    Hours or Days indicator of fishing time
    Enum:
    H
    D
  • total_gear : String
    Total gear in water.
  • gear_size : String
    Indicates how mesh size wass measured. Stretch Size (S) or Mesh length and width (M).
  • supplier_effort_id : String
    Unique effort id given by the caller. Only used to communicate errors and updates.
  • anything_caught : String
    anything caught flag (Y, N for YES, NO respectively).
  • catches : List
    Collection of catches made with this effort
  • gear_attributes : List
    Collection of supplemental attributes defining the gear configuration or effort.
  • effort_additional_attributes : List
    Collection of supplemental attributes defining the effort.
